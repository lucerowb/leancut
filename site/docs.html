LeanCut documentation

LeanCut turns long vlog footage into a tight cut using speech recognition and a language model that both run on your computer. This guide covers installing it, editing your first video, and fixing the problems people actually hit.

Install

LeanCut needs two things: the app itself, and a local language-model server (Ollama or LM Studio) that it talks to.

macOS (Apple Silicon)

  1. Download LeanCut-macOS.dmg from the project's Releases page.
  2. Open it and drag LeanCut into Applications.
  3. The first time, right-click LeanCut and choose Open. macOS asks once because the app is not notarized by Apple yet. If it still refuses, open System Settings → Privacy & Security and click Open Anyway.

Windows 10 / 11 (64-bit)

  1. Download LeanCut-Windows.zip from the Releases page and extract it anywhere, for example C:\Apps\LeanCut.
  2. Run LeanCut.exe. If SmartScreen warns about an unknown publisher, click More info → Run anyway.
  3. LeanCut draws its window with Microsoft Edge WebView2, which ships with Windows 11 and current Windows 10. If the window stays blank, install the WebView2 Runtime from Microsoft.

Language-model server

Pick one. Both are free.

  • Ollama (simplest): install it from ollama.com, then pull a model that fits your memory (see Choosing models): 
    ollama pull qwen2.5:7b
    Ollama runs in the background at http://localhost:11434.
  • LM Studio: download a model such as Qwen 2.5 7B Instruct, open the Developer tab and click Start Server. It listens on http://localhost:1234/v1.

Run from source instead

Needs Python 3.10–3.12 (faster-whisper does not support newer versions yet).

python3.12 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt -r requirements-build.txt
python desktop.py                # native window
python app.py                    # or: browser UI at http://127.0.0.1:8765

First run

  1. Open the Setup tab. It shows whether FFmpeg was found (the app bundles its own) and which Whisper models are on disk.
  2. Click Download next to large-v3-turbo (about 1.6 GB, once). You can skip this; the model also downloads the first time you run an edit.
  3. Click Test connection. You should see “Connected · N model(s)”. If not, see Troubleshooting.
Everything after this is offline. The only network traffic LeanCut ever makes is this one-time model download from Hugging Face, plus requests to the language-model server on your own computer.

Editing workflow

1. Add clips

Click the drop zone to open the file picker and select your .mp4, .mov or .mkv files. In the desktop app, picked files are used where they are and never copied. Dragging files onto the drop zone copies them into LeanCut's data folder instead, which doubles the disk space they use. Use ↑ and ↓ to put clips in story order; the final video follows that order.

2. Set the options

Choose the Whisper model, the spoken language, your language-model server and model, and an optional target length such as 10-15 minutes. Every option is explained in the Options reference.

3. Run the auto-edit

Click ① Auto-edit with AI. The Processing panel shows each step: extracting audio, transcribing each clip, then asking the language model to score the transcript. Transcripts are cached, so re-running with a different target or model only repeats the fast last step.

4. Review and adjust

The timeline shows one lane per clip. Green blocks are kept, grey blocks are speech the AI cut, and the dark background is silence and noise that was never transcribed. Below it, every line of the transcript shows its score and the AI's reason, for example ★1 false start. Click a line to play it; tick or untick its checkbox to override the AI.

5. Export

Click ② Export video + EDL. When it finishes, click Open output folder to find final_youtube_cut.mp4 and final_youtube_cut.edl.

How the AI decides

Local language models are good at judging lines but bad at hitting a time budget, so LeanCut splits the job. The model scores every transcript segment, and LeanCut's own code decides what fits.

ScoreMeaning
★5Must keep: opening hook, key story beat, funny moment, sign-off
★4Strong: genuine reaction, greeting or banter, an insight
★3Fine: ordinary narration that keeps the story moving
★2Weak: logistics nobody needs, rambling
★1Cut: repeated take, false start, mumbling, unintelligible noise

Then one of three rules picks the kept segments:

  • No target length: keep everything scored 3 or higher, and never less than 30% of the talking.
  • Target longer than all the talking: cut only ★1 lines, and always keep at least 80%.
  • Target shorter than the talking: keep the highest-scored lines first until the target is reached.

Before scoring, LeanCut joins short fragments (“I” · “have to” · “go now.”) into whole thoughts of up to 20 seconds, so the model never keeps half a sentence. A pause longer than 1.5 seconds always stays a possible cut point. Each kept segment gets 0.15 s of padding, and kept segments less than 0.6 s apart are joined so the cut doesn't feel choppy.

Choosing models

Language model

The model's weights must fit in memory. On Apple Silicon that is the unified memory; on a PC it is RAM, plus GPU memory if you have one. LeanCut refuses an Ollama model larger than 75% of your memory, because such a model swaps to disk and can take hours per request.

MemorySuggested modelSize on disk
8 GBqwen2.5:3b, llama3.2:3babout 2 GB
16 GBqwen2.5:7b, llama3.1:8babout 5 GB
24 GBqwen2.5:14babout 9 GB
32 GB+qwen2.5:32b, gemma2:27b16–20 GB

“Thinking” models (Qwen 3, Gemma 4 and similar) work too. With Ollama, LeanCut turns their thinking off, since it only slows down a scoring job. In LM Studio, switch thinking off in the model's settings for the same speed-up.

Whisper model

tiny and base are for quick tests on English. small and medium are fine for clear English. large-v3-turbo is the default because it is far better on accents, wind and other languages, and on a modern CPU it is still quick: 22 minutes of footage transcribed in about 7 minutes on an M5 Pro Mac.

Non-English footage

Whisper's accuracy varies a lot by language. For widely spoken languages, set Spoken language to that language. For languages Whisper handles poorly, or for speech that mixes a language with English, set it to English. Whisper then writes a rough English version of what was said, with timestamps that still match the speech. That is the best input a local model can judge.

Real example. Nepali–English moto-vlog footage: small on auto-detect produced random characters from four different scripts, large-v3-turbo set to Nepali was still garbled and 11× slower, and large-v3-turbo set to English produced readable lines in 33 seconds per 2 minutes of audio.

With Auto-detect on, the Processing log shows the language Whisper detected and how sure it was. If that is wrong, set the language yourself.

Export & EDL

Every export writes two files to the output folder:

  • final_youtube_cut.mp4: H.264 video with 192 kbps AAC stereo audio at the first clip's resolution and frame rate. Frame-accurate mode uses quality level CRF 18, about 46 Mbps for 4K, which is fine to upload to YouTube as-is.
  • final_youtube_cut.edl: a CMX3600 edit list with one event per cut. Each event names its source clip, so your editor relinks to the originals.

Open the EDL in DaVinci Resolve

  1. Import your original clips into the Media Pool.
  2. File → Import → Timeline… and select the .edl.
  3. Leave “Automatically import source clips into media pool” on, and point it at the folder that holds your clips if asked.

Open the EDL in Premiere Pro

  1. File → Import… and select the .edl.
  2. Choose the sequence settings that match your footage, then relink the offline clips to your originals.
29.97 fps footage. The EDL uses non-drop-frame timecode and writes 29.97 fps as 30. Cuts can drift by about one frame per minute of timeline. 25, 30, 50 and 60 fps footage is exact.

Troubleshooting

Cannot reach the LLM server at …
The server isn't running or the URL is wrong. Start Ollama (it normally runs in the menu bar or system tray, or run ollama serve) or click Start Server in LM Studio, then click ↻ next to the model list. LeanCut checks this before transcribing, so you never wait through a long transcription only to fail at the end.
'model' needs 19.9 GB but this machine has 24 GB of memory
The model is too big to run without swapping. Pick a smaller one from the table above.
The LLM produced no output for 300 s
The model stopped responding, almost always because it doesn't fit in memory (LM Studio models aren't size-checked in advance). Load a smaller model or close other memory-hungry apps. A slow model that is still producing text never triggers this error.
The local LLM ran out of (V)RAM
The server failed to load the model. Unload other models in Ollama or LM Studio, or choose a smaller model or quantization (Q4).
Transcript looks like random characters
Whisper misheard the language. Switch to large-v3-turbo and set the spoken language. For mixed or less common languages choose English (see Non-English footage). Changing the model or language re-transcribes automatically.
The AI kept almost nothing (or everything)
Check the target length. With no target LeanCut keeps lines scored ★3+; with a target it keeps the best lines up to that length. Small models score less consistently, and a larger model gives steadier results.
A clip won't play in the preview
The built-in player can't decode some formats, such as certain HEVC .mov files. Processing and export still work; only the preview is affected.
GPU error during transcription
LeanCut retries on the CPU automatically and notes it in the log. To use an NVIDIA GPU on Windows, install CUDA 12 and cuDNN 9.
Nothing to render: no segments are marked as kept
Run the auto-edit first, or tick at least one line in the transcript.

Still stuck? The desktop app writes a log to leancut.log in the data folder (see below). Include it when you report a problem.

FAQ

Does LeanCut upload my footage?

No. Audio, transcripts and video stay on your computer. The only downloads are the Whisper model, once, and whatever models you pull into Ollama or LM Studio yourself.

Why did it drop my scenic riding shots?

Today LeanCut edits by what is said, so stretches with no talking are left out. Keeping scenic B-roll is the top item on the roadmap. Until then, add those shots back from the EDL timeline in your editor.

Can I use a cloud model instead?

Any OpenAI-compatible endpoint works through the LM Studio option, but your transcript text would then leave your machine, which defeats the point of LeanCut.

Does the export lose quality?

Fast mode copies the original video stream untouched. Frame-accurate mode re-encodes at CRF 18, which is visually lossless for YouTube.

What does it cost?

Nothing. LeanCut and all the models it uses are free to run.
