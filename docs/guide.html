LeanCut guide

LeanCut turns long vlog footage into a tight cut using speech recognition and a language model that both run on your computer, then lets you finish it in an editor or by telling an assistant what to change. This guide covers installing it, editing your first video, and fixing the problems people actually hit.

Install

LeanCut needs two things: the app itself, and a local language-model server (Ollama or LM Studio) that it talks to.

macOS (Apple Silicon)

  1. Download LeanCut-macOS.dmg from the project's Releases page.
  2. Open it and drag LeanCut into Applications.
  3. The first time, right-click LeanCut and choose Open. macOS asks once because the app is not notarized by Apple yet. If it still refuses, open System Settings → Privacy & Security and click Open Anyway.

Windows 10 / 11 (64-bit)

  1. Download LeanCut-Windows.zip from the Releases page and extract it anywhere, for example C:\Apps\LeanCut.
  2. Run LeanCut.exe. If SmartScreen warns about an unknown publisher, click More info → Run anyway.
  3. LeanCut draws its window with Microsoft Edge WebView2, which ships with Windows 11 and current Windows 10. If the window stays blank, install the WebView2 Runtime from Microsoft.

Linux (64-bit)

  1. Download LeanCut-Linux-x64.tar.gz from the Releases page. It needs Ubuntu 22.04, Debian 12 or another distribution with glibc 2.35 or newer.
  2. Extract it and run the installer. No root needed: 
    tar xzf LeanCut-Linux-x64.tar.gz
./LeanCut/install.sh
    It copies the app to ~/.local/share/LeanCut/app, adds LeanCut to your app menu and links ~/.local/bin/leancut. ./LeanCut/install.sh --remove uninstalls it and keeps your projects.
  3. Titles and captions need a bold system font: DejaVu Sans Bold (sudo apt install fonts-dejavu-core). System-voice previews need espeak-ng.
The Linux build is new. So far it has been tested by the automated release build, which starts it under a virtual display. Please report anything that doesn't work on your distribution.

Language-model server

Pick one. Both are free.

  • Ollama (simplest, and the one the decision engine needs): install it from ollama.com, then pull a model that fits your memory (see Choosing models): 
    ollama pull qwen2.5:7b
    Ollama runs in the background at http://localhost:11434.
  • LM Studio: download a model such as Qwen 2.5 7B Instruct, open the Developer tab and click Start Server. It listens on http://localhost:1234/v1.

Run from source instead

Needs Python 3.10–3.12 (faster-whisper does not support newer versions yet).

python3.12 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt -r requirements-build.txt
pip install "pywebview[qt]"      # Linux only: the native window
pip install -r requirements-voice.txt   # optional: local voice cloning (about 1 GB)
python desktop.py                # native window
python app.py                    # or: browser UI at http://127.0.0.1:8765

First run

  1. Open Settings and scroll to Models on disk. It shows whether FFmpeg was found (the app bundles its own) and which Whisper models are on disk.
  2. Click Download next to large-v3-turbo (about 1.6 GB, once). You can skip this; the model also downloads the first time you run an edit.
  3. Click Test LLM connection. You should see “Connected · N model(s)”. If not, see Troubleshooting.
  4. In Settings › AI models, choose your LLM model.
Everything after this is offline. Besides one-time model downloads, LeanCut only talks to the language-model server you chose and, unless you turn it off in Settings › Updates, makes an anonymous update check against GitHub. Details are in the privacy policy.

Editing workflow

1. Pick or create a project

Each trip or video is a project with its own clips, edit and exports. Switch projects from the menu at the top of the window, or manage them on the Projects tab.

2. Add clips

Click the drop zone in Media to open the file picker and select your .mp4, .mov or .mkv files. In the desktop app, picked files are used where they are and never copied. Dragging files onto the drop zone copies them into LeanCut's data folder instead, which doubles the disk space they use. Use ↑ and ↓ to put clips in story order; the final video follows that order. Files a camera split from one recording are joined into one clip as you add them.

Filmed the same moments on a second camera (a chest cam or a phone)? Set that clip's Camera menu to Angle of …. LeanCut lines it up with the main clip by comparing their audio and shows the offset. Second angles don't change the edit; they are attached to the FCPXML and OpenTimelineIO exports so you can switch angles in your editor.

3. Set the options

In Settings › AI models, choose the Whisper model, the spoken language, and your language-model server and model. In the editor's toolbar, set an optional Target length such as 10-15 min. Every option is explained in the Options reference.

4. Run the auto-edit

Click ① Auto-edit with AI. The Log tab shows each step:

  1. Extracts audio and transcribes each clip (cached, so this only happens once per clip, model and language).
  2. Measures every shot's colour and movement, and reads GoPro telemetry when there is some.
  3. Joins fragments into whole thoughts, marks retakes, and finds lines where you said a marker phrase.
  4. Listens for loud moments: shouts, laughs and revs that jump above the road noise.
  5. Asks the language model to score every line it hasn't scored before.
  6. Picks the lines that fit your target, then looks for scenic B-roll in the silent stretches.
  7. Writes suggestions for the edit.

AI scores are cached per line and model. Changing the target length and re-running costs no AI scoring time.

5. Review and polish

The result appears in the monitor and on the timeline. Press Space to watch it. Then change what you like, either by hand in the editor or by asking the assistant. Every change can be undone.

6. Export

Click ② Export. When it finishes, the Log lists every file it wrote; click Open output folder to see them. You can press Cancel at any time. Finished work is kept, and the next export reuses every part that was already rendered: a 4K re-export that took 9 minutes the first time took 28 seconds the second.

The editor

The Editor tab has your media on the left, the monitor in the middle, the assistant on the right, the timeline below them, and six tabs at the bottom: Inspector, Look & titles, Graphics, Transcript, Search footage and Log.

Monitor

The monitor has two modes.

  • Instant plays the edit straight from your source files, with nothing rendered. Colour, effects, titles, captions and intro and outro cards are drawn on top of the picture, and transitions show as a short dip. It's an approximation: LUTs aren't shown, transitions aren't the real ones, and voice-overs aren't heard (they appear on the Voice track).
  • Rendered plays an exact render. Click Render preview in the toolbar: LeanCut renders the whole edit at 540p with everything baked in, including voice-overs, music, bleeps and loudness, then the Rendered button turns on. Render again after you change something; unchanged parts are reused. Stabilisation and voice enhancement are left out of the preview to keep it quick; they're applied at export.

Timeline

The timeline shows the finished video, not your source clips, on six tracks: Graphics (animated graphics), B-roll (scenery laid over the talking), Video (every part in output order, with thumbnails; amber parts are B-roll shots of their own, ⏩ parts are fast-forward ride-throughs, badges show effects and speed), Audio (the waveform), Titles and Voice-over.

  • Select: click a part; ⇧-click selects a range, ⌘-click (Ctrl-click) adds or removes one. With several selected, the Inspector changes them all at once: cut, stabilise, effect, transition, colour or a title on each.
  • Trim: drag either edge of a part. With Snap on, the edge lands between words, never in the middle of one.
  • Split: put the playhead where you want it and press S (or ✂ Split). The two halves can then have different looks.
  • Scrub: drag along the ruler or an empty spot. Zoom with the slider, +/−, ⌘-scroll or a pinch; scroll to move along.
  • Move: drag a title, a graphic or a B-roll cutaway; drag the end of a title or graphic to change its length.

Text on the video

Press T+ Text (or T) to put text on the video at the playhead. Drag it anywhere on the monitor, scroll over it to make it bigger or smaller, and double-click it to type. It lasts 4 seconds; drag its end on the Titles track to change that. Double-click a burned-in caption on the monitor to correct its words. In Look & titles, tick Show them over the first and last shots to lay the intro and outro titles over your footage instead of on a card of their own.

Keys don't fire while you're typing in a field.

Inspector

Shows the selected part: its ids, where it comes from in the source clip, and what's said in it. From here you can play from the part, cut it, trim its start and end (in source seconds), set its effect, the transition into it and its length, give it its own colour preset, add or remove titles (text, style, seconds into the part, duration), add a voice-over line in your voice, and apply the suggestions that concern it.

Look & titles

Settings for the whole video: the cut style used at every cut and its length, colour (auto colour, a preset, five sliders and a LUT), the intro and outro cards, burned-in captions, face and plate blur, the B-roll share and the music volume. See Looks. The B-roll share is used when you run the auto-edit again.

Transcript

Cut by editing words: select words in the transcript (drag across them) and press Delete or Cut selected words. Just those words are cut, with a clean jump cut. Lines transcribed before v0.3 have no word timings, so their words are spread evenly over the line; run the auto-edit again for exact ones.

The source view: one lane per clip with kept lines in green, scenic B-roll in amber and cut speech in grey, and the full transcript below with each line's score and reason, for example ★1 earlier take of the next line. Tick or untick any line or B-roll window, drag the handles at either end of a kept block to trim it, and click a line or block to play it from the source clip (press ▶ to return to the edit). A ? marks lines the AI is unsure about.

Undo

Every edit can be undone: ticks and trims, Inspector and Look changes, an assistant request (as one step) and each applied suggestion. LeanCut keeps the last 40 steps per project until you quit.

AI assistant & suggestions

The Assistant panel takes instructions in your own words and turns them into edit actions with your local language model. It works on the result of the auto-edit, so run that first.

  • Make it about 8 minutes
  • Give it a warm cinematic look
  • Add an intro title “Day 3” with the subtitle “Into the hills”
  • Slow down the biggest reaction
  • Use J-cuts everywhere
  • Cut the fuel stop, and put a lower third “Day 2 · Nagarkot” on the first line
  • Crossfade into c1.s0 and make the B-roll black and white
  • Turn on captions and blur faces
  • Add a voice-over on c0.s4: “Forty minutes later, the fog finally lifted.”

The assistant sees a one-line summary of every part: its id, source time, whether it's kept, its score, its effects and what's said. Ids look like c0.s3 (a spoken line of the first clip) or c0.b1 (a B-roll window). It can keep, cut and trim parts, set effects and transitions, change the cut style, colour (for the whole video or single parts) and auto colour, add and remove titles and voice-overs, set the intro and outro, the target length, B-roll share and music volume, switch captions, blur and stabilisation, and add silent footage as B-roll.

LeanCut checks every action before applying it: unknown part ids, effects or out-of-range values are skipped and listed under the reply with the reason. Everything one request changed is one undo step. Questions get an answer and no changes. The model's answer is constrained to LeanCut's action format, so it can't reply with something LeanCut can't use, but a small model can still misread what you meant: check the result, and undo if needed. Target length and B-roll share take effect when you run the auto-edit again; that reuses the cached transcripts and scores.

Suggestions

After each auto-edit, the Suggestions tab lists ideas for the edit. Some come from fixed rules:

  • Your call: a line the decision engine is less than 55% sure about, with the opposite choice.
  • Add an intro title when there is none.
  • Turn on auto color when clips are under-exposed.
  • Smooth the cuts with J-cuts when there are more than 8 kept parts and every cut is a hard cut.
  • Punch in after more than 30 seconds of talking without a visual change.
  • Slow down the big reaction on a loud moment.
  • Stabilise the shaky shots in clips that move a lot between frames.

The language model adds up to 10 of its own, marked AI: titles where the place or day changes, transitions at scene changes, lines to cut or bring back. Suggestions that duplicate another or would change nothing are dropped. Click Apply or Dismiss on each, Apply all to take every open one (each is its own undo step), or Suggest again for a fresh list. Click a part id on a suggestion to jump to it. The Inspector shows the suggestions for the selected part.

Agents

For bigger jobs than a single instruction, let an agent work through the edit step by step. Pick one under Who edits in the Assistant panel:

  • Quick assistant: one request, one set of actions (as above).
  • Agent with tools runs on your own local model. It reads the edit, makes changes, adds or writes animated graphics, and looks at frames of the finished video to check its work, over several steps you can watch in the chat. It needs a model that can call tools: qwen2.5:14b, qwen2.5:7b, llama3.1:8b or qwen3:8b, for example. If the model can't see pictures, your vision model (such as gemma3:4b) describes each frame for it.
  • Codex, Claude Code, Gemini CLI or OpenCode, if installed and signed in: LeanCut starts it in the project folder with LeanCut's tools connected. These use their own service and account. Codex with a local gpt-oss model runs Codex on your machine instead; it needs ollama pull gpt-oss:20b (13 GB).

Every change an agent makes goes through the same checked actions as the Inspector, so it can't break the project, and Undo takes each step back. Cancel stops it. Small local models are capable but not perfect: they sometimes pick the wrong line, so watch the result.

Connect any coding agent

LeanCut is also an MCP server, so you can work from your coding agent's own window. Settings › Agents shows the exact line or config for Claude Code, Codex, Cursor, OpenCode, Gemini CLI and Qwen Code; from the packaged app the server command is LeanCut --mcp. Keep LeanCut open while the agent works: the agent finds it automatically. A terminal agent can also use the CLI, for example LeanCut --cli look 12.5 to save a frame. Details are in CONNECT_AGENTS.md.

Motion graphics

Animated graphics sit on the Graphics track over your footage: titles, lower thirds, chapter cards, location pins, end screens, quotes, a “time jump” clock, stat cards, and a speedometer and route map drawn from a GoPro's GPS. Open the Graphics tab, pick one, fill it in and click Add at the playhead. It plays live on the monitor and runs on across cuts; drag it on the track to move it, or its end to change its length.

Each graphic is a small web page in the project's graphics folder that draws any moment of itself, the same page format as OpenFilm. So you, or an agent, can write new ones: ask the agent for “an animated altitude chart for the climb” and it writes the page, checks it (errors, missing fonts, text off the frame, a picture that changes when it shouldn't) and places it. For export, LeanCut draws every frame with your installed Chrome, Edge, Brave or Chromium; if none is installed it downloads a headless Chrome (about 110 MB) the first time. Graphics stay in the MP4: edit lists don't carry them.

How the AI decides

Local language models are good at judging lines but bad at hitting a time budget, so LeanCut splits the job. The model scores every transcript line, and LeanCut's own code decides what fits. With the decision engine, scores are weighted averages such as ★3.6.

ScoreMeaning
★5Must keep: opening hook, key story beat, funny moment, sign-off
★4Strong: genuine reaction, greeting or banter, an insight
★3Fine: ordinary narration that keeps the story moving
★2Weak: logistics nobody needs, rambling
★1Cut: repeated take, false start, mumbling, unintelligible noise

Some lines are decided without asking the model:

  • Retakes: when two neighbouring lines are at least 75% the same words, the earlier one gets ★1. Whisper's repeat loops in wind noise (“She is the type of child. She is the type of child?”) are collapsed to one sentence first.
  • Spoken markers: lines within 30 seconds before a marker phrase get ★5. A line that is nothing but the phrase gets ★1, because viewers shouldn't hear “clip that”.
  • Loud moments: a line spoken during a loudness spike (at least 8 dB above the surrounding 20 seconds and in the clip's loudest 10%) gets +1, up to ★5. So does a line during a telemetry highlight.

Then one of three rules picks the kept lines:

  • No target length: keep everything scored 3 or higher, and never less than 30% of the talking.
  • Target longer than all the talking: cut only ★1 lines, and always keep at least 80%.
  • Target shorter than the talking: keep the highest-scored lines first until the target is reached.

Before scoring, LeanCut joins short fragments (“I” · “have to” · “go now.”) into whole thoughts of up to 20 seconds, so the model never keeps half a sentence. A pause longer than 1.5 seconds always stays a possible cut point. Each kept segment gets 0.15 s of padding, kept segments less than 0.6 s apart are joined, and every cut gets a 30 ms audio fade so it doesn't click over engine drone.

Scenic B-roll

LeanCut reads only the keyframes of each clip (about one per second; 22 minutes of 4K took under a minute on an M5 Pro, and the result is cached), measuring movement, colour and brightness. In silent stretches of at least 6 seconds it rates 5-second windows: steady movement and colour score high, the shakiest 5% (bumps, fast pans) and badly exposed frames score low. GoPro telemetry raises windows during a highlight and drops stopped and motorway stretches. With a visual judge set, a local vision model looks at the middle frame of the 16 best windows, describes it in a few words and rates it; that rating counts for half of the window's score. The best windows across the whole project are kept until the B-roll share is used. Without a visual judge this is a heuristic, not image recognition, so check the amber blocks before exporting.

Decision engine

The decision engine is how LeanCut scores lines by default. It's an open, local take on the idea behind TypeSafe's Jev and OpenJev: instead of asking the model to write a JSON list of scores, LeanCut asks it one short question at a time and reads the probability it gives to each possible answer.

  • For each line it asks “score it 1–5” and reads the probabilities of ★1 to ★5 from the model's first answer token (Ollama's logprobs). The score is their weighted average, and the confidence is how much of the probability sits on the most likely digit.
  • It then asks which of 11 fixed reasons fits best (opening hook, story beat, funny moment, genuine reaction, greeting or banter, insight, logistics, rambling, false start or repeat, unintelligible, sign-off) and takes the most likely one.
  • Lines under 55% confidence get a ? in the transcript and a “Your call” suggestion.

The model never writes free text, so there's nothing to parse or repair. The transcript sits at the start of every question, where the server's prompt cache reuses it: the first question pays for reading it (about 6.8 s in our test), and each question after that costs about 0.2 s. On our demo project 7 lines took about 6 s; the batch scorer took about 2.5 minutes for a 146-line project, which we estimate at about 45 s with the decision engine.

It needs a server that returns token probabilities: a recent Ollama does. LM Studio and other servers that don't are scored in batches automatically, and the Log says so. Choose the behaviour in Settings › AI models › Scoring engine.

It learns your taste

Every line you keep or cut yourself (in the transcript, with the Delete key, through the assistant or by applying a suggestion) is saved in taste.json in the data folder, up to the last 200. The decision engine shows the model your 8 most recent kept and 8 most recent cut lines as examples, so the cut drifts towards your taste. The batch scorer doesn't use them. Delete taste.json to start over.

Constrained output

When the assistant and the suggestions answer, the server is given a JSON schema of LeanCut's actions (Ollama's format, LM Studio's json_schema) and can only produce text that matches it. This is the open, local equivalent of ScaleDown's constrained decoding models. Batch scoring and the YouTube text use the servers' plain JSON mode with a forgiving parser and a retry.

Looks

Looks are rendered into the MP4. The instant preview approximates them; Render preview shows them exactly. Any look makes the export frame-accurate.

Transitions

Set a cut style for every cut in Look & titles, or a transition into one part in the Inspector. Choices: cut, J-cut, crossfade, dissolve, dip to black, dip to white, wipe left or right, slide left or right, circle, radial, zoom, pixelize and smooth. Length is 0.1–2 s (0.6 s by default, 0.4 s for a J-cut) and never more than half of either part. A J-cut keeps the hard picture cut but starts the next line's sound under the end of the previous shot, which hides jump cuts. Edits with only hard cuts are joined losslessly; any transition joins all parts in one extra encoding pass.

Colour

Colour is applied in layers: auto colour per clip, then the preset, then the sliders, then a part's own colour.

  • Auto color balances every clip from its keyframe measurements: exposure (±0.5), contrast and saturation, so dark or flat clips match the rest.
  • Look presets: punchy, warm, cool, cinematic, teal & orange, moody, vintage, bright, and black & white.
  • Sliders: exposure, contrast, saturation, temperature and vignette. Reset manual color clears them and the LUT.
  • LUT: a .cube or .3dl file, applied after the other corrections. It isn't shown in the instant preview.
  • Color for this part in the Inspector gives one part its own preset on top of the video's look.

Titles

Four styles, each fading in and out over 0.3 s, for 1–15 seconds:

  • Title: large, centred.
  • Lower third: bottom left on a dark box, above any captions.
  • Caption: bottom centre.
  • Label: small, top left.

A title belongs to a part and moves with it when you trim. Titles use a bold system font (Arial Bold or Helvetica on macOS, Segoe UI Bold or Arial Bold on Windows, DejaVu Sans Bold on Linux); LeanCut doesn't bundle one, and without one titles and captions are left out.

Intro and outro cards

A title and optional subtitle over moving footage, darkened and softened, for 4 seconds. The intro plays over your best kept B-roll shot and fades into the first part; the outro plays over the last seconds of the final part. Styles: Bold (large and centred), Minimal (a lower third) and Cinematic (centred, with letterbox bars). Set them in Look & titles and click Save intro & outro, or ask the assistant.

Burned-in captions

Burn in captions draws every kept line's words at the bottom of the picture, wrapped at 42 characters, for viewers who watch muted. The .srt export is separate and works either way.

Voice-overs & voice cloning

A voice-over is a typed line spoken over a part, in your own cloned voice when that's set up. Add one in the Inspector (Voice-over, with the seconds into the part) or ask the assistant. Hear it plays it before you add it. Voice-overs are mixed into the video with the original sound ducked underneath, and they're heard in the rendered preview and the export, not in Instant mode. Each line is generated once and cached.

Engines

Your voice sample

  1. In Settings › Voice, tick This is my own voice, or I have permission to clone it. LeanCut won't make a sample without it.
  2. Click Use my voice from this project. LeanCut takes the clip with the most speech and picks the cleanest 8–20 second run of your lines: steady loudness, few pauses, no shouts, gusts or clipping, since cloning copies whatever is in the sample. It's saved as voices/<project>.wav in the data folder. Or click Choose a voice sample… to use a recording of your own.
  3. Type a line under Hear it to check how it sounds.
Only clone your own voice, or one you have permission to use. Don't use it to impersonate anyone. Speech made with Chatterbox carries Resemble AI's inaudible Perth watermark. See the terms.

Running voice_server.py

Chatterbox pins its own versions of NumPy, PyTorch and Transformers. If they clash with LeanCut's, or you use the packaged app, run the voice server in a separate virtual environment from a source checkout:

pip install -r requirements.txt -r requirements-voice.txt
python voice_server.py --voice my_voice.wav      # --port 8880 by default

--voice (required) is the reference recording used as the default voice; --port sets the port. The first start downloads the model (about 3.8 GB). Then in Settings › Voice choose Voice server and enter http://127.0.0.1:8880/v1. With the voice name empty, LeanCut sends the path of your current voice sample and the server reads it from disk; or register a recording with POST /v1/voices?name=me and enter me. The server only listens on 127.0.0.1 and only answers local requests.

Footage search

The Search footage tab finds shots by what's in them: type “lake”, “hairpin”, “sunset” or “friends laughing”. It uses CLIP, an image model that runs on your CPU; it downloads once (about 150 MB). The first search indexes each clip: one frame every 2 seconds from the keyframes, about 50 seconds per hour of 4K in our test, and the index is cached. Later searches are almost instant.

You get the 24 best matches as thumbnails. Click one to look at it in the monitor, or + B-roll to add 5 seconds around it to the cut as kept B-roll (undoable). CLIP understands English queries best.

Privacy blur

Tick Blur faces & licence plates in Look & titles, and choose what to look for in Settings › Rider AI › Blur. At export (and in the rendered preview), LeanCut checks two frames a second of every part with two small detectors, YuNet for faces and LPD-YuNet for plates (4 MB together, downloaded once), follows each detection over time and blurs a padded box around it.

Check the result before you publish. The detectors work on a 640-pixel copy of the frame, so faces smaller than about 60 pixels in 4K (10 pixels at that size) are missed, as are many faces turned away from the camera. The plate model was trained on Chinese plates and scores plates from other countries much lower, so it misses many of them. Shorts are blurred too; thumbnails and the intro and outro backgrounds aren't.

Stabilisation

Built in

Set the Stabilise effect on a part in the Inspector, ask the assistant to “stabilise the shaky shots”, or apply the suggestion LeanCut makes for clips that move a lot. At export, FFmpeg's vid.stab analyses the part's motion in a first pass and smooths it in a second, zooming in slightly to hide the moving edges. It's applied at export only, not in either preview.

With Gyroflow

Gyroflow uses the gyro data many action cameras record, which gives far steadier results, including horizon lock.

  1. Open the clip in Gyroflow, stabilise it, and export it to the same folder as the original with Gyroflow's default _stabilized suffix, for example GX010042_stabilized.mp4. Don't trim it.
  2. In LeanCut's Media list, click Use Gyroflow export on that clip. LeanCut checks the lengths match and swaps the file in; your edit stays as it is.
  3. Use original swaps back.

This works on single files, not on clips joined from camera chapters.

Camera chapters

Action cameras split long recordings into several files (GoPro at about 4 GB, DJI by time). With Settings › Rider AI › Join camera chapter files automatically on, a file you add is joined onto the clip before it when:

  • both have the same resolution and frame rate, and
  • the names follow GoPro's chapter numbering (GX010042 then GX020042; GH, GX, GO and GP prefixes), or the new file's start timecode is within 3 frames of where the previous file ended.

Add the files in recording order. The joined clip is shown as, for example, GX010042.MP4 (+2 chapters) and is transcribed and edited as one recording, so moments across the split survive. FFmpeg reads the files in place through a list; nothing is copied. The EDL, FCPXML and OTIO point at the real chapter files. Turn the setting off to keep files separate.

Telemetry

GoPro cameras record a GPS track inside the MP4 when GPS is on. With Settings › Rider AI › Use GoPro GPS telemetry on, LeanCut reads it during the auto-edit and finds:

WhatHow it's found
Hard brakingSlowing by more than 0.4 g for at least half a second
TwistiesHard left and right turns within 8 seconds of each other, kept up for at least 10 seconds
Top speedThe fastest 3% of the moving time
SummitThe highest point within 30 seconds either side, at least 30 m above the low points around it
StoppedBelow about 5 km/h for at least 8 seconds
MotorwayAbove about 80 km/h, dead straight, for at least a minute

A line spoken during a highlight gets +1 on its score, like a loud moment, and B-roll during a highlight ranks higher. B-roll from stopped and motorway stretches is left out. Clips without telemetry, or without a GPS lock, are edited as before.

Checked on real GoPro files. The parser matches GoPro's own reference parser exactly on HERO5 to HERO13 files (HERO11 and newer write the newer GPS9 format, which is supported), and readings with a poor GPS fix are dropped. The riding thresholds haven't been checked on a real motorcycle ride yet: the only openly licensed GPS ride we found is a bicycle. If a highlight looks wrong on your footage, please open an issue.

Profanity bleep

Turn on Settings › Audio › Bleep profanity. At export and in the rendered preview, swear words in kept lines are muted and covered with a 1 kHz tone, and in burned-in captions they're masked (“f***”). LeanCut knows common English swear words; add others, in any language, under Extra words to bleep.

Bleeps use Whisper's own word timings for clips transcribed with v0.3 or later. For clips transcribed earlier, a line's words are spread evenly across it, so a bleep can land slightly early or late: check them in the rendered preview, or change the Whisper model or language once to re-transcribe. The exported .srt and burned-in captions show the word masked (f***).

Voice enhancement

Settings › Audio › Neural voice enhancement runs DeepFilterNet3, a small speech-enhancement model, over the finished video's sound on your CPU. It keeps your voice and removes engine rumble and wind. In our tests it improved a synthetic 0 dB engine-noise mix by 10.7 dB SNR and processed 30 minutes of stereo audio in 37 seconds, using about 0.6 GB of memory.

The model (8 MB) is downloaded once from GitHub and checked against a fixed checksum. Enhancement runs at export only, before music and voice-overs are mixed in. You can use it with or instead of the simpler Reduce wind and road noise filter.

Choosing models

Language model

The model's weights must fit in memory. On Apple Silicon that is the unified memory; on a PC it is RAM, plus GPU memory if you have one. LeanCut refuses an Ollama model larger than 75% of your memory, because such a model swaps to disk and can take hours per request.

MemorySuggested modelSize on disk
8 GBqwen2.5:3b, llama3.2:3babout 2 GB
16 GBqwen2.5:7b, llama3.1:8babout 5 GB
24 GBqwen2.5:14babout 9 GB
32 GB+qwen2.5:32b, gemma2:27b16–20 GB

“Thinking” models (Qwen 3, Gemma 4 and similar) work too. With Ollama, LeanCut turns their thinking off, since it only slows down a scoring job. In LM Studio, switch thinking off in the model's settings for the same speed-up. The assistant and suggestions use a 16k-token context; on very long projects a small model may follow instructions less reliably.

Vision model (visual judge)

Optional. Pull a small vision model into Ollama, for example ollama pull gemma3:4b, and choose it in Settings › AI models › Visual judge. It looks at the 16 best B-roll candidates on every auto-edit, about 4.7 seconds per frame with gemma3:4b in our test. It needs to fit in memory next to your language model. Its rating comes from token probabilities, so it needs Ollama.

Whisper model

tiny and base are for quick tests on English. small and medium are fine for clear English. large-v3-turbo is the default because it is far better on accents, wind and other languages, and on a modern CPU it is still quick: 22 minutes of footage transcribed in about 7 minutes on an M5 Pro Mac.

Custom and fine-tuned Whisper models

Any Whisper model converted to CTranslate2 works, including community models fine-tuned for one language. Enter its Hugging Face repo id (for example Systran/faster-whisper-large-v3) or a local folder in Settings › Models on disk › Custom Whisper model. To convert a Transformers checkpoint yourself:

pip install ctranslate2 transformers torch
ct2-transformers-converter --model <org/whisper-model> --output_dir whisper-ct2 \
  --copy_files tokenizer.json preprocessor_config.json --quantization float16

Non-English footage

Whisper's accuracy varies a lot by language. For widely spoken languages, set Spoken language to that language. For languages Whisper handles poorly, a model fine-tuned for that language is far better than the stock ones: set Spoken language to it and paste the model's Hugging Face name (or a local folder) into Settings › Models on disk › Custom Whisper model. Models must be in CTranslate2 format; tools/convert_whisper.py converts a Hugging Face Whisper fine-tune.

Nepali (tested on real moto-vlog footage). Stock Whisper doesn't work: large-v3-turbo set to English writes fluent English that is mostly made up (a 15-second sentence about food came out as “Thank you.”), auto-detect wanders into other scripts, and turbo can't even recognise Nepali as a language. Dragneel/whisper-medium-nepali-openslr-ct2 (Apache-2.0, 0.8 GB) with Spoken language: Nepali writes plausible Nepali in Devanagari, at about 0.6× real time on an M-series Mac (a 22-minute ride takes about 35 minutes). Your language model then judges the Nepali text directly; larger models handle that better. For Hindi, bjollans/whisper-large-v3-vaani-hindi-ct2 and digikar/vasista22-whisper-hindi-large-v2-ct2-int8 (both Apache-2.0) are ready to use; avoid models marked non-commercial (CC-BY-NC).

Burned-in captions in Devanagari need a title font that has those letters; on most systems the default bold font doesn't, so check the preview. With Auto-detect on, the Log shows the language Whisper detected and how sure it was. A mode that switches between Nepali or Hindi and English line by line is being worked on and isn't in this version.

Every file starts with the name pattern from Settings (by default, the project name).

Camera timecode is respected. DJI and GoPro write time-of-day timecode (for example 21:01:21;28, drop-frame at 29.97 fps). LeanCut writes source times on that timecode, in drop-frame where the camera uses it, so editors place every cut on the right frames. Effects, transitions, titles, colour, voice-overs and ride-through fast-forwards exist only in the MP4; the edit lists carry the cuts.

Open the edit in DaVinci Resolve

  1. Import your original clips into the Media Pool.
  2. File → Import → Timeline… and select the .fcpxml, .otio or .edl.
  3. Leave “Automatically import source clips into media pool” on, and point it at the folder that holds your clips if asked.

Open the edit in Premiere Pro

  1. File → Import… and select the .edl.
  2. Choose the sequence settings that match your footage, then relink the offline clips to your originals.

Open the edit in Final Cut Pro

  1. File → Import → XML… and select the .fcpxml. A new event named LeanCut appears with the project inside.

Projects & overnight batch

The Projects tab lists every project with its clip count, total footage and whether it has been edited. Remove moves a project's folder aside (to projects/.trash-… in the data folder) rather than deleting it, and your original footage is never touched.

To process several rides unattended, tick them, choose Auto-edit, Export or both, and click Run batch. Projects run one after another with the current settings; if one fails, the rest still run and the log names the failures at the end. Cancel stops the whole batch.

Updates

When LeanCut starts, it asks GitHub for the latest release (at most every six hours). If a newer version exists, a banner says so, with What's new for the release notes.

  1. Click Install in the banner (or in Settings › Updates). LeanCut downloads the release for your system from the project's GitHub releases, checks it's complete, and unpacks it next to the app.
  2. Click Restart to finish. LeanCut quits, a small helper swaps in the new version and starts it. If anything goes wrong, the old version is put back and started instead.

Projects and settings live in the data folder and are never touched. In-app installs have been tested on macOS; on Windows and Linux they're new, so if one fails, download the release by hand. If LeanCut can't install where it is (for example a folder you can't write to, or when running from source), the banner offers Download instead: quit LeanCut and replace the app with the new one. Turn the check off in Settings › Updates; Check now still works.

Troubleshooting

Cannot reach the LLM server at …
The server isn't running or the URL is wrong. Start Ollama (it normally runs in the menu bar or system tray, or run ollama serve) or click Start Server in LM Studio, then click ↻ next to the model list. LeanCut checks this before transcribing, so you never wait through a long transcription only to fail at the end.
'model' needs 19.9 GB but this machine has 24 GB of memory
The model is too big to run without swapping. Pick a smaller one from the table above.
The LLM produced no output for 300 s
The model stopped responding, almost always because it doesn't fit in memory (LM Studio models aren't size-checked in advance). Load a smaller model or close other memory-hungry apps. A slow model that is still producing text never triggers this error.
The local LLM ran out of (V)RAM
The server failed to load the model. Unload other models in Ollama or LM Studio, or choose a smaller model or quantization (Q4).
no logprobs: this server/model doesn't return token probabilities
You chose Decision engine only on a server that can't return token probabilities (LM Studio, or an older Ollama). Update Ollama, or choose the default scoring engine, which falls back to batch scoring.
Run the auto-edit first, so the assistant has parts to work with.
The assistant edits the result of an auto-edit. Click ① Auto-edit with AI first.
Search needs the vision module. · The voice module isn't installed in this build. · Voice enhancement needs the enhance module; skipped. · Face & plate blur needs the vision module; skipped.
The optional module or one of its libraries is missing, which happens when running from source without all of requirements.txt. Run pip install -r requirements.txt again. In the packaged apps these modules are included; if you see this there, please report it.
No voice engine is available. See Settings › Voice.
None of the voice engines works on this computer: Chatterbox isn't installed, no voice server is reachable, and there's no system voice (on Linux, install espeak-ng). See Voice-overs.
Voice cloning isn't installed in this LeanCut.
You chose the Chatterbox engine in an app without it. Install requirements-voice.txt in a source checkout, or start voice_server.py and choose the voice-server engine.
Cannot reach the voice server at …
Start it with python voice_server.py --voice my_voice.wav and check the URL ends in /v1.
Visual judge stopped: …
The model chosen as visual judge can't look at images or can't return token probabilities. Choose a vision model in Ollama, such as gemma3:4b, or set the visual judge to empty. The auto-edit carries on without it.
Privacy blur missed a face or a plate
Small faces (under about 60 pixels tall in 4K), faces turned away and most non-Chinese licence plates can be missed. See Privacy blur; blur what's left in your editor, or cut the shot.
Titles or captions don't appear in the video
LeanCut didn't find a bold system font. On Linux, install fonts-dejavu-core.
No Gyroflow export found next to …
Export from Gyroflow into the same folder as the original, keeping the _stabilized suffix, and without trimming.
Transcript looks like random characters
Whisper misheard the language. Switch to large-v3-turbo and set the spoken language. For mixed or less common languages choose English (see Non-English footage). Changing the model or language re-transcribes automatically.
The AI kept almost nothing (or everything)
Check the target length. With no target LeanCut keeps lines scored ★3+; with a target it keeps the best lines up to that length. Small models score less consistently, and a larger model gives steadier results.
No working hardware H.264 encoder was found
You chose Hardware only on a computer without one (or without current GPU drivers). Choose Auto, which falls back to software encoding.
ffmpeg failed: …
The message shows FFmpeg's first error lines and the end of its log. Include it when you report a problem.
Sync confidence is low
The two cameras' audio didn't match well, for example when one mic only hears wind. Check the offset in your editor, or remove the angle and line it up by hand.
A clip won't play in the preview
The built-in player can't decode some formats, such as certain HEVC .mov files. Processing and export still work; only the instant preview is affected. Render preview shows the edit anyway.
GPU error during transcription
LeanCut retries on the CPU automatically and notes it in the log. To use an NVIDIA GPU on Windows, install CUDA 12 and cuDNN 9.
No segments are marked to keep. Run the auto-edit or tick some lines first.
Run the auto-edit first, or tick at least one line in the transcript.
LeanCut only accepts requests from its own window
Something other than LeanCut's own window tried to use its local server, for example a web page. That's blocked on purpose. If you run python app.py, open it at http://127.0.0.1:8765 or http://localhost:8765.

Still stuck? The desktop app writes a log to leancut.log in the data folder (see below). Include it when you report a problem.

FAQ

Does LeanCut upload my footage?

No. Audio, transcripts and video stay on your computer. Network traffic is limited to one-time model downloads, the language-model and voice servers you choose (on your own computer by default), and the optional update check and download.

Does it keep scenic riding shots without talking?

Yes. Scenic B-roll fills a share of the video (15% by default) with the most interesting silent footage, optionally rated by a local vision model. Turn it off or change the share in Settings › Rider AI.

Can I use a cloud model instead?

Any OpenAI-compatible endpoint works through the LM Studio option, but your transcript text would then leave your machine, which defeats the point of LeanCut.

Can LeanCut use ScaleDown CDMs or Jev?

Not directly. ScaleDown's CDMs and TypeSafe's Jev are hosted, closed-weight APIs with no free local version. VideoJev has open weights (Apache-2.0) but needs an NVIDIA GPU with CUDA 12.8 and FlashAttention and has no serving support. None of them runs on a typical Mac or PC. LeanCut implements the ideas locally instead: schema-constrained output (like CDMs), decisions read from token probabilities (like Jev and OpenJev), and a local vision model for visual judgement (a lighter stand-in for VideoJev).

Do my effects and titles reach Resolve or Final Cut?

Not yet. The EDL, FCPXML and OTIO carry the cuts; looks, titles, transitions and voice-overs are baked into the MP4 only.

Does the export lose quality?

Fast mode copies the original video stream untouched. Frame-accurate mode re-encodes at CRF 18 in software, or at about 0.12 bits per pixel with a hardware encoder; both look clean on YouTube.

What does it cost?

Nothing. LeanCut and all the models it uses are free to run.
