LeanCut guide

LeanCut turns long vlog footage into a tight cut using speech recognition and a language model that both run on your computer. This guide covers installing it, editing your first video, and fixing the problems people actually hit.

Install

LeanCut needs two things: the app itself, and a local language-model server (Ollama or LM Studio) that it talks to.

macOS (Apple Silicon)

  1. Download LeanCut-macOS.dmg from the project's Releases page.
  2. Open it and drag LeanCut into Applications.
  3. The first time, right-click LeanCut and choose Open. macOS asks once because the app is not notarized by Apple yet. If it still refuses, open System Settings → Privacy & Security and click Open Anyway.

Windows 10 / 11 (64-bit)

  1. Download LeanCut-Windows.zip from the Releases page and extract it anywhere, for example C:\Apps\LeanCut.
  2. Run LeanCut.exe. If SmartScreen warns about an unknown publisher, click More info → Run anyway.
  3. LeanCut draws its window with Microsoft Edge WebView2, which ships with Windows 11 and current Windows 10. If the window stays blank, install the WebView2 Runtime from Microsoft.

Language-model server

Pick one. Both are free.

  • Ollama (simplest): install it from ollama.com, then pull a model that fits your memory (see Choosing models): 
    ollama pull qwen2.5:7b
    Ollama runs in the background at http://localhost:11434.
  • LM Studio: download a model such as Qwen 2.5 7B Instruct, open the Developer tab and click Start Server. It listens on http://localhost:1234/v1.

Run from source instead

Needs Python 3.10–3.12 (faster-whisper does not support newer versions yet).

python3.12 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt -r requirements-build.txt
python desktop.py                # native window
python app.py                    # or: browser UI at http://127.0.0.1:8765

First run

  1. Open Settings and scroll to Models. It shows whether FFmpeg was found (the app bundles its own) and which Whisper models are on disk.
  2. Click Download next to large-v3-turbo (about 1.6 GB, once). You can skip this; the model also downloads the first time you run an edit.
  3. Click Test LLM connection. You should see “Connected · N model(s)”. If not, see Troubleshooting.
Everything after this is offline. Besides the one-time model download from Hugging Face, LeanCut only talks to the language-model server you chose and, unless you turn it off in Settings › Updates, makes an anonymous update check against GitHub. Details are in the privacy policy.

Editing workflow

1. Pick or create a project

Each trip or video is a project with its own clips, edit and exports. Switch projects from the menu at the top of the window, or manage them on the Projects tab.

2. Add clips

Click the drop zone to open the file picker and select your .mp4, .mov or .mkv files. In the desktop app, picked files are used where they are and never copied. Dragging files onto the drop zone copies them into LeanCut's data folder instead, which doubles the disk space they use. Use ↑ and ↓ to put clips in story order; the final video follows that order.

Filmed the same moments on a second camera (a chest cam or a phone)? Set that clip's Camera menu to Second angle of …. LeanCut lines it up with the main clip by comparing their audio and shows the offset. Second angles don't change the edit; they are attached to the FCPXML and OpenTimelineIO exports so you can switch angles in your editor.

3. Set the options

In Models & API, choose the Whisper model, the spoken language, your language-model server and model, and an optional target length such as 10-15 minutes. Everything else (export formats, destination, audio, B-roll) lives on the Settings tab. Every option is explained in the Options reference.

4. Run the auto-edit

Click ① Auto-edit with AI. The Processing panel shows each step:

  1. Extracts audio and transcribes each clip (cached, so this only happens once per clip, model and language).
  2. Joins fragments into whole thoughts, marks retakes, and finds lines where you said a marker phrase.
  3. Listens for loud moments: shouts, laughs and revs that jump above the road noise.
  4. Asks the language model to score every line it hasn't scored before.
  5. Picks the lines that fit your target, then looks for scenic B-roll in the silent stretches.

AI scores are cached per line and model. Changing the target length and re-running costs no AI time at all.

5. Review and adjust

The timeline shows one lane per clip. Green blocks are kept lines, amber blocks are scenic B-roll (dashed when not used), grey blocks are speech the AI cut, and the dark background is silence that was never transcribed.

  • Trim: drag the handles at either end of a kept block.
  • Preview: click a block or a transcript line.
  • Override: tick or untick any line or B-roll window. Every line shows its score and the reason, for example ★1 earlier take of the next line.

6. Export

Click ② Export. When it finishes, the Processing panel lists every file it wrote; click Open output folder to see them. You can press Cancel at any time. Finished work is kept, and the next export reuses every part that was already rendered: a 4K re-export that took 9 minutes the first time took 28 seconds the second.

How the AI decides

Local language models are good at judging lines but bad at hitting a time budget, so LeanCut splits the job. The model scores every transcript line, and LeanCut's own code decides what fits.

ScoreMeaning
★5Must keep: opening hook, key story beat, funny moment, sign-off
★4Strong: genuine reaction, greeting or banter, an insight
★3Fine: ordinary narration that keeps the story moving
★2Weak: logistics nobody needs, rambling
★1Cut: repeated take, false start, mumbling, unintelligible noise

Some lines are decided without asking the model:

  • Retakes: when two neighbouring lines are at least 75% the same words, the earlier one gets ★1. Whisper's repeat loops in wind noise (“She is the type of child. She is the type of child?”) are collapsed to one sentence first.
  • Spoken markers: lines within 30 seconds before a marker phrase get ★5. A line that is nothing but the phrase gets ★1, because viewers shouldn't hear “clip that”.
  • Loud moments: a line spoken during a loudness spike (at least 8 dB above the surrounding 20 seconds and in the clip's loudest 10%) gets +1, up to ★5.

Then one of three rules picks the kept lines:

  • No target length: keep everything scored 3 or higher, and never less than 30% of the talking.
  • Target longer than all the talking: cut only ★1 lines, and always keep at least 80%.
  • Target shorter than the talking: keep the highest-scored lines first until the target is reached.

Before scoring, LeanCut joins short fragments (“I” · “have to” · “go now.”) into whole thoughts of up to 20 seconds, so the model never keeps half a sentence. A pause longer than 1.5 seconds always stays a possible cut point. Each kept segment gets 0.15 s of padding, kept segments less than 0.6 s apart are joined, and every cut gets a 30 ms audio fade so it doesn't click over engine drone.

Scenic B-roll

LeanCut reads only the keyframes of each clip (about one per second; 22 minutes of 4K took under a minute on an M5 Pro, and the result is cached), measuring movement, colour and brightness. In silent stretches of at least 6 seconds it rates 5-second windows: steady movement and colour score high, the shakiest 5% (bumps, fast pans) and badly exposed frames score low. The best windows across the whole project are kept until the B-roll share is used. This is a heuristic, not an image-recognition model, so check the amber blocks before exporting.

Choosing models

Language model

The model's weights must fit in memory. On Apple Silicon that is the unified memory; on a PC it is RAM, plus GPU memory if you have one. LeanCut refuses an Ollama model larger than 75% of your memory, because such a model swaps to disk and can take hours per request.

MemorySuggested modelSize on disk
8 GBqwen2.5:3b, llama3.2:3babout 2 GB
16 GBqwen2.5:7b, llama3.1:8babout 5 GB
24 GBqwen2.5:14babout 9 GB
32 GB+qwen2.5:32b, gemma2:27b16–20 GB

“Thinking” models (Qwen 3, Gemma 4 and similar) work too. With Ollama, LeanCut turns their thinking off, since it only slows down a scoring job. In LM Studio, switch thinking off in the model's settings for the same speed-up.

Whisper model

tiny and base are for quick tests on English. small and medium are fine for clear English. large-v3-turbo is the default because it is far better on accents, wind and other languages, and on a modern CPU it is still quick: 22 minutes of footage transcribed in about 7 minutes on an M5 Pro Mac.

Custom and fine-tuned Whisper models

Any Whisper model converted to CTranslate2 works, including community models fine-tuned for one language. Enter its Hugging Face repo id (for example Systran/faster-whisper-large-v3) or a local folder in Settings › Models › Custom Whisper model. To convert a Transformers checkpoint yourself:

pip install ctranslate2 transformers torch
ct2-transformers-converter --model <org/whisper-model> --output_dir whisper-ct2 \
  --copy_files tokenizer.json preprocessor_config.json --quantization float16

Non-English footage

Whisper's accuracy varies a lot by language. For widely spoken languages, set Spoken language to that language. For languages Whisper handles poorly, or for speech that mixes a language with English, set it to English. Whisper then writes a rough English version of what was said, with timestamps that still match the speech. That is the best input a local model can judge.

Real example. Nepali–English moto-vlog footage: small on auto-detect produced random characters from four different scripts, large-v3-turbo set to Nepali was still garbled and 11× slower, and large-v3-turbo set to English produced readable lines in 33 seconds per 2 minutes of audio.

With Auto-detect on, the Processing log shows the language Whisper detected and how sure it was. If that is wrong, set the language yourself. A fine-tuned model for your language (see above) is the other option.

Export

Every file starts with the name pattern from Settings (by default, the project name).

FileWhat it is
.mp4The finished video: H.264 at the first clip's resolution and frame rate, 192 kbps AAC stereo, loudness-matched. Hardware encoding targets about 0.12 bits per pixel (≈30 Mbps for 4K30); software uses CRF 18.
.srtSubtitles for the kept lines, timed to the cut and split into cues of up to 84 characters. Upload it to YouTube next to the video.
_youtube.txtA title, a description, tags and chapters written by your language model. Chapters follow YouTube's rules: the first at 0:00, at least 10 seconds apart, at least three of them.
_thumb_1…6.jpgThe sharpest, best-exposed frames from the top-scored moments and B-roll, at full resolution.
.edlCMX3600 edit list for Resolve and Premiere.
.fcpxmlFCPXML 1.10 for Final Cut Pro and Resolve, with chapter markers and any synced second angle as a connected clip.
.otioOpenTimelineIO for Resolve 18.5+ and other OTIO tools: V1 and A1 hold the cut, V2 the synced second angle.
_short_N.mp4Vertical 1080×1920 Shorts: the best continuous 15–58 second stretches by score, centre-cropped.
Camera timecode is respected. DJI and GoPro write time-of-day timecode (for example 21:01:21;28, drop-frame at 29.97 fps). LeanCut writes source times on that timecode, in drop-frame where the camera uses it, so editors place every cut on the right frames. Ride-through fast-forwards exist only in the MP4; the edit lists leave them out.

Open the edit in DaVinci Resolve

  1. Import your original clips into the Media Pool.
  2. File → Import → Timeline… and select the .fcpxml, .otio or .edl.
  3. Leave “Automatically import source clips into media pool” on, and point it at the folder that holds your clips if asked.

Open the edit in Premiere Pro

  1. File → Import… and select the .edl.
  2. Choose the sequence settings that match your footage, then relink the offline clips to your originals.

Open the edit in Final Cut Pro

  1. File → Import → XML… and select the .fcpxml. A new event named LeanCut appears with the project inside.

Projects & overnight batch

The Projects tab lists every project with its clip count, total footage and whether it has been edited. Remove moves a project's folder aside (to projects/.trash-… in the data folder) rather than deleting it, and your original footage is never touched.

To process several rides unattended, tick them, choose Auto-edit, Export or both, and click Run batch. Projects run one after another with the current settings; if one fails, the rest still run and the log names the failures at the end. Cancel stops the whole batch.

Updates

When LeanCut starts, it asks GitHub for the latest release (at most every six hours). If a newer version exists, a banner offers the download for your system (the macOS .dmg or the Windows .zip) and the release notes. To update, quit LeanCut and replace the app with the new one; projects and settings live in the data folder and are kept. Turn the check off in Settings › Updates; Check now still works.

Troubleshooting

Cannot reach the LLM server at …
The server isn't running or the URL is wrong. Start Ollama (it normally runs in the menu bar or system tray, or run ollama serve) or click Start Server in LM Studio, then click ↻ next to the model list. LeanCut checks this before transcribing, so you never wait through a long transcription only to fail at the end.
'model' needs 19.9 GB but this machine has 24 GB of memory
The model is too big to run without swapping. Pick a smaller one from the table above.
The LLM produced no output for 300 s
The model stopped responding, almost always because it doesn't fit in memory (LM Studio models aren't size-checked in advance). Load a smaller model or close other memory-hungry apps. A slow model that is still producing text never triggers this error.
The local LLM ran out of (V)RAM
The server failed to load the model. Unload other models in Ollama or LM Studio, or choose a smaller model or quantization (Q4).
Transcript looks like random characters
Whisper misheard the language. Switch to large-v3-turbo and set the spoken language. For mixed or less common languages choose English (see Non-English footage). Changing the model or language re-transcribes automatically.
The AI kept almost nothing (or everything)
Check the target length. With no target LeanCut keeps lines scored ★3+; with a target it keeps the best lines up to that length. Small models score less consistently, and a larger model gives steadier results.
No working hardware H.264 encoder was found
You chose Hardware only on a computer without one (or without current GPU drivers). Choose Auto, which falls back to software encoding.
Sync confidence is low
The two cameras' audio didn't match well, for example when one mic only hears wind. Check the offset in your editor, or remove the angle and line it up by hand.
A clip won't play in the preview
The built-in player can't decode some formats, such as certain HEVC .mov files. Processing and export still work; only the preview is affected.
GPU error during transcription
LeanCut retries on the CPU automatically and notes it in the log. To use an NVIDIA GPU on Windows, install CUDA 12 and cuDNN 9.
Nothing to render: no segments are marked as kept
Run the auto-edit first, or tick at least one line in the transcript.
LeanCut only accepts requests from its own window
Something other than LeanCut's own window tried to use its local server, for example a web page. That's blocked on purpose. If you run python app.py, open it at http://127.0.0.1:8765 or http://localhost:8765.

Still stuck? The desktop app writes a log to leancut.log in the data folder (see below). Include it when you report a problem.

Inside the data folder: settings.json holds your settings; projects/<id>/project.json holds each project's clips, transcripts and edit, with its exports in projects/<id>/output unless you chose another export folder; cache/ holds extracted audio, keyframe measurements and rendered parts (safe to delete; it is rebuilt when needed); media/ holds clips you dragged in. Set the LEANCUT_HOME environment variable to use a different folder. Removing a clip only deletes copies LeanCut made itself, never your original footage. Projects from v0.1 are moved into this layout automatically the first time v0.2 starts.

Roadmap

Version 0.2 shipped the whole first roadmap. What's next, picked from what riders ask for and what similar tools offer:

Next up

Learns your tasteFeed the lines you re-tick or untick back into the prompt as examples, so the cut gets more like yours over time.

FAQ

Does LeanCut upload my footage?

No. Audio, transcripts and video stay on your computer. Network traffic is limited to downloading Whisper models from Hugging Face, the language-model server you choose (on your own computer by default), and the optional update check.

Does it keep scenic riding shots without talking?

Yes, since v0.2. Scenic B-roll fills a share of the video (15% by default) with the most interesting silent footage. Turn it off or change the share in Settings › Rider AI.

Can I use a cloud model instead?

Any OpenAI-compatible endpoint works through the LM Studio option, but your transcript text would then leave your machine, which defeats the point of LeanCut.

Does the export lose quality?

Fast mode copies the original video stream untouched. Frame-accurate mode re-encodes at CRF 18 in software, or at about 0.12 bits per pixel with a hardware encoder; both look clean on YouTube.

What does it cost?

Nothing. LeanCut and all the models it uses are free to run.
